#Descripción del Caso

Este proyecto consiste en el diseño e implementación de una base de datos para la gestión
de un sistema de ventas de equipamiento deportivo. Su propósito es administrar el ciclo de 
vida completo de los productos, desde la gestión de proveedores y la reposición de stock 
hasta el procesamiento final de las ventas a los clientes, el registro detallado de las 
transacciones y la generación formal de comprobantes.
