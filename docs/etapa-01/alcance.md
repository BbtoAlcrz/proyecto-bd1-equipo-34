# Alcance Del Sistema

El sistema comienza por la gestión de artículos deportivos clasificados por 
categorías junto con datos de clientes y proveedores. El proceso de ventas incluye varios 
métodos de pago, el registro de los artículos adquiridos y la emisión de factura al cliente, 
actualizando el inventario y aplicando los descuentos correspondientes en las existencias 
para asegurar que el stock nunca sea negativo. La gestión de compras a proveedores es 
realizada por el administrador del local y registrando el detalle de los artículos adquiridos. 
Finalmente, se incluye una gestión de comunicación que permite registrar los datos de los 
clientes para el envío de notificaciones sobre ofertas comerciales.
